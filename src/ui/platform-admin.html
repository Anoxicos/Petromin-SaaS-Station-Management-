Onboard a client

Before you start
  1. Ask the station owner to create or activate their account using your organization’s Auth0 process.
  2. Have the owner sign in to the station app in a new tab at least once.
  3. Return here and enter the same email address. This form links the existing account; it does not create an Auth0 login.

For each station, use confirmed operating details for meter mode, cutoff time, and IANA time zone. Leave the business-day rule pending until operations confirms it.
